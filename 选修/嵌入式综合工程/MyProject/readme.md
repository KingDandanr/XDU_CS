# 基本配置

## 硬件配置

- **左边板子 (Left Board)**：地址必须是 **`0x40`** (默认地址，不焊接)。
- **右边板子 (Right Board)**：地址必须是 **`0x41`** (需要在 A0 处焊接短路)。

代码里的 `part_index` (0, 1, 2) 对应的是：

- **0** = **Coxa (根部)**：连接身体的关节。
- **1** = **Femur (大腿)**：中间的关节。
- **2** = **Tibia (小腿)**：最末端、连接脚尖的关节。

## 软件操作

### 代码介绍

这个项目里，path_utils和pihexa两个文件夹是整个项目的核心，分工非常明确。简单来说：**`pihexa` 是机器人的“大脑和四肢”**，而 **`path_utils` 是机器人的“数学课本”**。

#### `pihexa` 核心驱动层

包含了机器人的**物理定义**、**运动学算法**和**硬件驱动**。如果机器人腿接反了、走歪了，都要在这里改。

里面的关键文件及作用：

- **`leg.py` (腿部类)**：
  - **作用：** 定义了单条腿的结构。负责**逆运动学 (Inverse Kinematics, IK)** 的计算。
  - **核心逻辑：** 告诉它“脚尖要移动到坐标 (x, y, z)”，它利用数学公式算出“大腿舵机、小腿舵机、根部舵机各需要转多少度”。
- **`hexapod.py` (六足主体类)**：
  - **作用：** 它把 6 条 `Leg` 组合在一起，代表整个机器人。它负责接收高级指令（比如“前进”、“旋转”），然后指挥 6 条腿协同工作。
- **`movement.py` (步态生成)**：
  - **作用：** 定义了机器人怎么走。比如“三角步态 (Tripod Gait)”：哪几条腿抬起，哪几条腿支撑，抬多高，跨多远。
  - **重要性：** 机器人走得顺不顺，全看这里。
- **`base.py` 或 `settings.py` (配置)**：
  - 通常包含舵机的 GPIO 引脚映射、舵机偏移量（Offset）校准数据。

#### `path_utils` 

纯数学计算，用来让机器人的动作看起来更**自然、流畅**。

- **`bezier.py` (贝塞尔曲线)**：
  - **作用：** 规划脚尖的轨迹。
  - **原理：** 当机器人迈出一步时，脚尖不是直上直下的（那样很生硬），而是画一条平滑的弧线（半圆形）。贝塞尔曲线就是用来生成这条弧线的数学公式。
  - **效果：** 让机器人的脚像生物一样柔顺地抬起和放下，减少跺脚的冲击。
- **`interpolation.py` (插值算法)**：
  - **作用：** 填补动作之间的空白。
  - **原理：** 舵机不能从 0度 瞬间跳到 90度。插值算法会在 0 到 90 之间生成一系列中间值（0, 5, 10, ... 90），让舵机平滑转过去。

####  工作原理

当你点击网页上的 **"Forward" (前进)** 按钮时，代码内部是这样跑的：

1. **`main.py` (Web端)**：收到“前进”指令，传给 `pihexa`。
2. **`pihexa/movement.py`**：决定接下来的一步，腿应该抬多高、迈多远。
3. **`path_utils/bezier.py`**：计算出脚尖在空中划过的优美弧线轨迹点 (x, y, z)。
4. **`pihexa/leg.py` (IK)**：把这些轨迹点 (x, y, z) 换算成 18 个舵机的角度。
5. **驱动层**：通过 I2C 把角度发给 PCA9685 驱动板。
6. **硬件**：舵机转动，机器人迈出一步。

### 调试操作

使用REALVNC进行可视化操作，使用手机热点，在树莓派中配置好，电脑也连接手机热点，可以在手机看到树莓派IP地址

在电脑上打开realVNC，输入树莓派地址进行连接，进入操作

首先更新树莓派系统并安装依赖

```bash
# 更新系统源和软件包 
sudo apt update && sudo apt upgrade -y 

# 安装核心依赖（Python是PiHexa18的主要开发语言） 
sudo apt install -y python3 python3-pip python3-rpi.gpio git 

# 安装舵机/机器人控制相关库 
pip3 install RPi.GPIO adafruit-circuitpython-servokit flask  
```

进入你编写好的项目文件

如果没有，可克隆本项目

```bash
# 进入用户目录（方便管理） 
cd ~ 

# 克隆官方代码库（如果有分支指定，替换成对应分支） 
git clone https://github.com/[此项目地址].git  

# 进入项目目录 
cd PiHexa18 #我这里沿用原项目名
```

运行硬件测试脚本

```bash
sudo python3 servo.py
```

运行主程序

```bash
sudo cd ~/PiHexa18/pihexa && python3 running.py
```

```bash
python pihexa/animate.py
```
