编译需要执行的命令：
mvn clean  // 清除之前的编译结果
mvn compile // source目录下的所有java程序都被编译成了class文件


运行需要执行的命令：
java -cp .\target\classes dc.sockettest.EchoServer
在另一个终端中运行：
java -cp .\target\classes dc.sockettest.EchoClient


环境：
jdk11
maven 3.8.4

用了腾讯的maven仓库镜像：
<mirror>
     <id>nexus-tencentyun</id>
     <mirrorOf>*</mirrorOf>
     <name>Nexus tencentyun</name>
     <url>http://mirrors.cloud.tencent.com/nexus/repository/maven-public/</url>
 </mirror>
