## 课程设计内容

设计一个可以通过微机键盘演奏不同音乐的控制系统，系统通过按下微机键盘模拟电子琴驱动实验箱的蜂鸣器发声，实现演奏音乐的功能

实现的基本功能如下：

1. 通过按键，可以模拟电子琴演奏包含高、中、低音
2. 可以自动演奏乐曲，通过设定好的程序按对应按键自动播放
3. 设置多个模式，可在液晶屏切换和查看当前状态
4. 可以通过串口与上位机交互，屏幕上显示21个琴键（高中低音），按下某键时微机蜂鸣器会有所反应

## 核心功能代码部分

### 蜂鸣器

```c
void Set_Frequence(int f)
{
  // 重新设计分频
  long long int div=TIM0_CLK/f;
  unsigned char low=div&0x00ff;
  unsigned char high=(div&0xff00)>>8; //低高字节
  outportb(Con_8253,0x36);     //计数器T0设置在模3状态,二进制计数
  outportb(T0_8253,low);      //CLK0/div
  outportb(T0_8253,high); 
}

void Beep(int f,int div)
// 参数频率f和步长div
// 保持的时间长度1，2，4，8分别代表几分音符
{
  int time=60000/BPM/div*4;//一拍持续的时间，以ms为单位 BPM=120
  if(f==0)   Delay_ms(time); //f为0就静音
  else{
    Set_Frequence(f);
    Enable_beep();//启用蜂鸣器
    Delay_ms(time);
    Disable_beep();//关闭蜂鸣器
  }
}

// num - ms为单位的延迟
void Delay_ms(int num)
{
  static long long int i=0;
  long long int div=(TIM1_CLK/1000)*num;
  unsigned char low=div&0x00ff;
  unsigned char high=(div&0xff00)>>8; 
  outportb(Con_8253,0x70);     //计数器T1设置在模0状态,二进制计数
  outportb(T1_8253,low);      //CLK1/div
  outportb(T1_8253,high);
  while(sign)
  {
    i++;   
    if(i>=1000000)break;//防止卡死
  }
  i=0;
  sign=1;
}
```

}

## 总结与反思

本次课设软硬件相结合，同时与部分乐理知识相关，在提升自己实践能力的同时还理解了相关的音符产生原理等，获取了非常多新知识

实验过程中，也发现了一些问题：

实验箱的硬件出现问题，这种情况需要我们在实验前先通过对例程的测试来确保硬件功能的正常，实验中出现不明失常（比如我们的蜂鸣器在打开电源时会发出尖锐暴鸣，中间突然不叫了）可以利用蜂鸣器发声检测哪部分信号传输出现问题，比如实验箱一8253的out1无法输出，实验箱二的串口控制芯片部分无法输入

在实验结束时，蜂鸣器的叫声低音部分依旧难听，可以通过电容滤波来优化，试验箱最左边还有一个蜂鸣器，试了一下优美太多了

软件交互功能部分也一定要确定数据的获取，最好循环才能一直测试，否则只响一次可能以为是硬件问题

使用继电器来控制蜂鸣器发声，但是继电器在高频下会失真，这点也要注意
