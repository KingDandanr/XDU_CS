# 论文初稿（第 1 章与第 2 章）

## 第 1 章 绪论

### 1.1 研究背景与意义

近年来，随着人工智能、机器人技术和智能交通技术的快速发展，无人智能车辆在园区配送、仓储物流、安防巡检、灾害救援以及复杂危险环境作业等领域得到了越来越广泛的应用。无人智能车辆能够替代人工完成重复性高、危险性强或精度要求高的任务，因此具有重要的工程应用价值和现实意义。

在无人智能车辆的自主运行过程中，环境感知、路径规划和运动控制是决定系统性能的关键环节。其中，避障决策能力直接关系到车辆运行的安全性、稳定性和任务完成效率。若车辆不能在复杂环境中及时识别障碍物并做出合理决策，便可能出现碰撞、路径失效甚至任务中断等问题。因此，研究无人智能车辆的自主避障方法具有十分重要的理论意义和应用价值。

传统无人车辆避障方法主要包括基于规则的方法、基于图搜索的方法以及基于人工势场的方法等。这些方法在结构简单、环境已知或障碍物静止的场景中具有较好的效果，但当环境复杂度提高、障碍物具有动态变化特征或系统对实时性提出更高要求时，传统方法往往面临建模困难、鲁棒性不足以及泛化能力有限等问题。尤其是在动态障碍物场景下，无人车辆不仅需要考虑当前位置与目标位置之间的关系，还需要综合分析周围障碍物的运动趋势，从而在短时间内完成连续决策。这对传统方法提出了较大挑战。

深度强化学习作为近年来人工智能领域的重要研究方向，将强化学习的序列决策能力与深度神经网络的特征表达能力相结合，使智能体能够在与环境的交互过程中通过试错学习获得最优或近优策略。与传统规则式方法相比，深度强化学习能够在复杂环境中直接从状态输入中学习决策策略，减少对人工设计特征和精确模型的依赖。对于无人智能车辆避障问题而言，深度强化学习能够将环境状态、障碍物分布、目标位置等信息统一映射到动作决策上，具有较强的自适应能力和潜在的泛化能力。

基于上述背景，本文围绕“基于深度强化学习的无人智能车辆避障方法”开展研究，利用 Python 平台构建二维仿真环境，引入静态障碍物与动态障碍物，设计适用于无人智能车辆避障任务的状态空间、动作空间与奖励函数，并采用深度强化学习算法对模型进行训练与测试。本文的研究工作不仅能够为无人智能车辆自主避障方法提供一种有效实现思路，也能为深度强化学习在智能交通与移动机器人领域的应用提供实验参考。

### 1.2 国内外研究现状

#### 1.2.1 深度强化学习研究现状

强化学习是一种通过智能体与环境不断交互、依据奖励信号更新策略的机器学习方法。早期强化学习方法主要依赖表格型值函数表示方式，适用于状态空间和动作空间规模较小的问题。当问题规模扩大后，传统强化学习方法难以有效处理高维状态输入。随着深度学习的发展，研究人员开始使用深度神经网络对值函数或策略函数进行逼近，由此形成深度强化学习方法。

深度强化学习的重要代表算法包括深度 Q 网络（Deep Q-Network, DQN）、深度确定性策略梯度（Deep Deterministic Policy Gradient, DDPG）、近端策略优化（Proximal Policy Optimization, PPO）等。DQN 在离散动作控制问题中表现突出，能够通过经验回放和目标网络机制缓解训练不稳定问题；DDPG 面向连续动作控制任务，在机器人控制领域具有较高应用价值；PPO 通过引入裁剪机制约束策略更新幅度，在训练稳定性和实现复杂度之间取得了较好平衡，因此被广泛应用于机器人导航、避障控制和无人系统决策等任务中。

当前，深度强化学习的研究重点主要集中在以下几个方面：一是提升训练稳定性与样本利用效率；二是增强模型在复杂动态环境中的泛化能力；三是将感知、决策与控制进行统一建模；四是推动仿真训练结果向真实系统迁移。总体来看，深度强化学习已经从理论探索逐渐走向工程应用，在自主驾驶、机械臂控制、智能体博弈和机器人导航等方向均表现出较强潜力。

#### 1.2.2 无人智能车辆决策方法研究现状

无人智能车辆的决策与避障方法大体可以分为传统方法与智能学习方法两类。

传统方法中，A*、Dijkstra 等图搜索算法通过构建环境地图并搜索最优路径，适用于静态已知环境；人工势场法通过引入目标吸引力与障碍物斥力来实现实时避障，算法结构简单、实时性较好，但容易出现局部极小值问题；动态窗口法（Dynamic Window Approach, DWA）通过在速度空间中搜索可行动作，能够兼顾运动学约束与局部避障需求，在移动机器人领域应用广泛。这些方法具有可解释性强、实现相对简单等优点，但通常需要较准确的环境模型和人工规则设计，在复杂动态环境下性能容易下降。

随着机器学习和深度学习的发展，越来越多研究工作开始尝试将神经网络、模仿学习和强化学习方法应用于无人车辆的决策问题中。相比传统方法，学习型方法能够从环境交互数据中自动提取决策特征，在高维复杂场景中具有更强的适应能力。尤其是深度强化学习方法，能够直接以目标位置、障碍物信息和车辆状态作为输入，通过长期累计奖励来学习避障策略，因此在动态障碍规避和自主导航任务中受到广泛关注。

目前，无人智能车辆避障研究的一个重要发展趋势，是从单一静态环境下的路径规划转向复杂动态环境中的实时自主决策。研究对象也从理想化仿真环境逐步扩展到更接近真实场景的混合障碍环境。与此同时，评价指标不再仅关注是否到达目标，还包括碰撞率、路径效率、实时性和算法鲁棒性等多方面内容。

#### 1.2.3 存在的问题与发展趋势

尽管深度强化学习在无人智能车辆避障中取得了一定研究进展，但仍存在一些问题。首先，模型训练通常依赖大量环境交互样本，训练成本较高；其次，奖励函数设计对最终策略效果影响明显，不合理的奖励设置容易导致策略偏差；再次，仿真环境与真实环境之间存在差异，模型泛化能力和迁移能力仍有待提升。此外，在动态障碍物环境中，智能体需要同时处理目标趋近、障碍规避和路径效率等多个目标，决策难度较高。

未来的发展趋势主要体现在以下几个方面：一是构建更加符合真实应用需求的仿真环境，提高模型训练质量；二是将深度强化学习与传统路径规划、模型预测控制等方法进行融合，形成兼具可解释性与自适应能力的混合方法；三是研究更高效的训练机制与更稳定的奖励设计策略；四是推动仿真训练结果向真实车辆平台迁移，实现从理论验证到工程落地的进一步发展。

## 第 2 章 深度强化学习与无人智能车辆避障理论基础

### 2.1 强化学习基本概念

强化学习是一种面向序列决策问题的机器学习方法，其核心思想是智能体在环境中采取动作并接收奖励，根据长期累计奖励最大化原则不断调整自身策略，从而学会完成特定任务。与监督学习依赖标签样本不同，强化学习不直接提供标准答案，而是通过环境反馈让智能体在试错中学习最优决策方式。

在强化学习框架中，通常包含以下几个基本要素：

1. 智能体（Agent）：执行决策的主体。在本文中，智能体表示无人智能车辆。
2. 环境（Environment）：智能体所处的外部系统。在本文中，环境为包含起点、目标点、静态障碍物和动态障碍物的二维仿真空间。
3. 状态（State）：对环境当前信息的描述，用于表示智能体所处情形。
4. 动作（Action）：智能体在某一状态下可采取的操作。
5. 奖励（Reward）：环境对智能体当前动作反馈的评价信号。
6. 策略（Policy）：智能体在不同状态下选择动作的规则。

强化学习问题通常可抽象为马尔可夫决策过程（Markov Decision Process, MDP）。一个标准的 MDP 可表示为五元组 \((S, A, P, R, \gamma)\)，其中 \(S\) 表示状态空间，\(A\) 表示动作空间，\(P\) 表示状态转移概率，\(R\) 表示奖励函数，\(\gamma\) 表示折扣因子。折扣因子用于平衡当前奖励与未来奖励的重要程度，其取值范围通常在 0 到 1 之间。

在避障任务中，智能体不仅要考虑当前一步动作是否安全，还要考虑该动作对后续路径与最终到达目标的影响，因此强化学习适合处理此类需要长期收益优化的问题。

### 2.2 深度强化学习基本原理

传统强化学习方法在状态空间较小时可以通过表格形式存储值函数或策略，但当状态维度升高后，表格法会面临“维度灾难”问题，难以直接应用于复杂场景。深度强化学习通过引入深度神经网络，对值函数、策略函数或状态动作值函数进行逼近，从而使强化学习能够处理高维状态输入问题。

深度强化学习方法主要可以分为三类：

1. 基于值函数的方法。该类方法学习状态值函数或动作值函数，并依据值函数大小选择动作。DQN 是其中的典型代表。
2. 基于策略的方法。该类方法直接学习从状态到动作的映射关系，即策略函数。
3. Actor-Critic 方法。该类方法同时学习策略函数和价值函数，其中 Actor 负责选择动作，Critic 负责评价动作效果，是当前应用较广的一类深度强化学习方法。

深度强化学习的优势主要体现在以下几个方面：一是能够自动从原始状态信息中提取高层特征；二是适合解决复杂环境中的高维决策问题；三是可以在无需精确模型的前提下，通过与环境交互学习策略。在无人智能车辆避障任务中，深度强化学习能够综合考虑目标位置、障碍物分布、边界信息等多种因素，形成较为灵活的决策策略。

### 2.3 PPO 算法原理

在深度强化学习算法中，近端策略优化（Proximal Policy Optimization, PPO）是一种典型的策略梯度类算法。PPO 通过限制策略更新幅度，提高了训练过程的稳定性，兼顾了实现难度和算法性能，因此在机器人控制与自主导航任务中得到了广泛应用。

PPO 属于 Actor-Critic 框架。Actor 网络根据当前状态输出动作策略，Critic 网络对当前状态或状态动作对进行价值评估。训练过程中，智能体根据当前策略与环境交互，获得状态转移序列与奖励信息，再利用这些样本更新策略和价值网络参数。

PPO 的核心思想是通过裁剪目标函数限制新旧策略之间的差异，避免一次更新步长过大导致训练震荡。相比传统策略梯度方法，PPO 在训练中具有以下优点：

1. 训练稳定性较好；
2. 参数更新过程相对简单；
3. 对超参数敏感程度相对适中；
4. 适用于多种离散或连续控制任务。

对于本文中的无人智能车辆避障问题，车辆需要根据环境状态不断进行动作选择，属于连续交互式决策任务。PPO 能够在多轮交互中逐步优化策略，使车辆学会在趋近目标的同时规避障碍物，因此适合作为本文的核心算法。

### 2.4 无人智能车辆避障问题建模

为了将无人智能车辆避障任务转化为强化学习问题，需要对状态空间、动作空间和奖励函数进行建模。

#### 2.4.1 状态空间建模

状态空间用于描述车辆在某一时刻所感知到的环境信息。为了兼顾环境表示能力与训练复杂度，本文将状态信息设计为以下几部分：

1. 车辆当前位置；
2. 目标点相对位置；
3. 车辆与环境边界的相对距离；
4. 最近若干障碍物的相对位置；
5. 障碍物半径；
6. 动态障碍物速度信息。

通过上述状态设计，智能体能够同时感知目标方向与周边障碍分布，从而为避障决策提供基础信息。

#### 2.4.2 动作空间建模

本文采用离散动作空间，将车辆运动方向划分为 8 个动作，分别表示向右、右上、向上、左上、向左、左下、向下和右下八个方向。采用离散动作空间有两个主要原因：一是实现简单、易于训练；二是便于在本科毕业设计阶段快速验证深度强化学习方法在避障任务中的有效性。

#### 2.4.3 奖励函数建模

奖励函数是强化学习任务设计中的关键环节，其作用在于引导智能体形成期望行为。本文奖励函数主要由以下几部分构成：

1. 当车辆接近目标点时，给予正奖励；
2. 每执行一步动作时，给予较小负奖励，以抑制无效游走；
3. 当车辆过于接近障碍物时，给予惩罚；
4. 当车辆与障碍物发生碰撞时，给予较大负奖励；
5. 当车辆成功到达目标点时，给予较大正奖励。

这种奖励设计能够同时兼顾“尽快到达目标”和“避免碰撞障碍”两个目标，从而提升策略学习效果。

### 2.5 本章小结

本章介绍了强化学习与深度强化学习的基本概念，分析了 PPO 算法的核心思想与适用性，并结合无人智能车辆避障任务，对状态空间、动作空间和奖励函数进行了问题建模。上述理论分析为后续仿真环境设计、模型训练与实验验证提供了理论基础。

## 第 3 章 无人智能车辆避障环境设计

### 3.1 仿真环境总体设计

为了验证深度强化学习在无人智能车辆避障任务中的有效性，本文在 Python 平台下构建了一个二维仿真环境。该环境以平面坐标系作为车辆运行空间，在有限区域内设置车辆起点、目标点以及不同类型的障碍物，并通过环境状态更新机制模拟车辆与障碍物之间的动态交互过程。

与真实无人车辆系统相比，二维仿真环境忽略了复杂的车辆动力学细节和高维传感器输入，但能够保留避障问题中的核心决策特征，即车辆需要依据当前位置、目标方向和障碍物分布信息实时选择运动方向，从而在避免碰撞的前提下尽可能高效地到达目标点。对于本科毕业设计而言，该建模方式兼顾了实现难度、实验可控性和算法验证价值，适合作为深度强化学习避障研究的基础平台。

本文所设计环境的主要组成部分包括：

1. 二维平面地图；
2. 起点与目标点；
3. 静态障碍物；
4. 动态障碍物；
5. 状态更新与终止判定机制。

环境空间采用边长固定的正方形区域，车辆从起点出发，在障碍物约束下向目标点运动。若车辆到达目标点，则任务成功结束；若车辆与障碍物发生碰撞，则判定任务失败；若在规定最大步数内仍未到达目标，则当前回合终止。

### 3.2 状态空间设计

状态空间的设计直接影响深度强化学习模型的学习效果。状态信息过少会导致智能体缺乏必要环境感知能力，难以形成合理避障策略；状态信息过多则会增加训练复杂度，降低训练效率。为此，本文在兼顾表达能力和简洁性的前提下，对状态空间进行了设计。

本文将无人智能车辆在某一时刻的状态表示为一个定长向量，主要包含以下信息：

1. 车辆当前位置坐标；
2. 目标点相对车辆的位置；
3. 车辆到环境边界的距离；
4. 最近 3 个障碍物相对车辆的位置；
5. 障碍物半径；
6. 障碍物速度信息。

其中，车辆当前位置用于反映当前运动状态；目标点相对位置用于指导车辆整体运动方向；边界距离信息能够帮助车辆避免贴边运行；最近障碍物信息则用于局部避障决策。对障碍物仅取最近的若干个，而非全部障碍物，主要是为了降低状态维度并突出局部危险区域对决策的主要影响。对于障碍物数量不足的情况，则采用零填充方式保持状态维度一致。

在实现过程中，为了提高训练稳定性，本文还对状态数据进行了归一化处理，使不同量纲的数据映射到相对统一的数值范围内。这样做有助于深度神经网络更稳定地学习状态特征，提高训练效率。

### 3.3 动作空间设计

动作空间描述了智能体在每个决策时刻可以采取的行为方式。考虑到本文主要关注无人车辆避障策略本身，而非复杂车辆动力学控制，因此采用离散动作空间进行建模。

本文将车辆的动作空间划分为 8 个基本运动方向，分别为：

1. 向右；
2. 右上；
3. 向上；
4. 左上；
5. 向左；
6. 左下；
7. 向下；
8. 右下。

每个动作对应二维平面中的一个单位方向向量，车辆在执行动作时按预设步长向对应方向移动。采用这种动作空间设计的原因主要有以下几点：

1. 实现简单，便于快速构建强化学习环境；
2. 能够覆盖二维平面中的主要运动方向，满足基本避障需求；
3. 与 PPO 算法配合较为方便，训练过程稳定；
4. 便于后续实验分析与路径可视化。

虽然离散动作空间与真实车辆连续控制方式相比存在一定简化，但对于验证深度强化学习避障能力已经具备足够代表性。在后续研究中，可进一步扩展为连续动作控制形式，以提升模型的平滑控制能力和真实迁移潜力。

### 3.4 奖励函数设计

奖励函数是强化学习环境设计的关键部分，其作用是通过正负反馈引导智能体逐步学习期望行为。对于无人智能车辆避障任务而言，理想策略应同时满足两个目标：一是尽快到达目标点，二是在运动过程中避免与障碍物发生碰撞。因此，本文围绕这两个目标设计奖励函数。

本文奖励函数由以下几部分组成：

1. 目标趋近奖励：当车辆执行动作后距离目标点更近时，给予正奖励；
2. 步长惩罚：每执行一步动作，给予小幅负奖励，以避免车辆无效徘徊；
3. 障碍接近惩罚：当车辆距离障碍物过近时，给予惩罚；
4. 碰撞惩罚：当车辆与障碍物发生碰撞时，给予较大负奖励；
5. 目标到达奖励：当车辆成功到达目标点时，给予较大正奖励。

这种奖励设计体现了“鼓励接近目标、惩罚碰撞和无效运动”的基本思想。若仅设置到达目标和碰撞惩罚，而缺乏中间过程反馈，模型在训练初期往往难以获得有效学习信号；而加入距离变化奖励后，智能体能够逐步感知“哪些行为有助于靠近目标”，从而加快学习过程。另一方面，对于靠近障碍物的行为增加额外惩罚，则有利于提升策略的安全性，使车辆形成更加稳健的避障习惯。

### 3.5 障碍物模型设计

为了满足任务书中“障碍物包括静止和运动障碍物”的要求，本文在环境中分别设计了静态障碍物模型和动态障碍物模型。

静态障碍物在整个回合过程中位置保持不变，主要用于模拟道路边界障碍、固定设施或静止障碍物体。静态障碍物模型实现简单，但能够有效检验模型的基本绕障能力。

动态障碍物在每一步环境更新时依据预设速度改变位置，并在接触边界后改变运动方向，以模拟环境中可能出现的移动障碍。动态障碍物的引入显著提高了任务复杂度，因为车辆不仅需要根据当前障碍位置进行避障，还需要综合考虑障碍物未来运动趋势，从而体现深度强化学习在动态决策问题中的优势。

为了兼顾环境复杂度与训练难度，本文将障碍物统一抽象为圆形区域。圆形障碍模型便于进行碰撞检测与安全距离计算，也便于后续可视化展示。

### 3.6 测试场景设计

为了系统验证所构建模型的避障能力，本文设计了 3 类典型测试场景：

#### 3.6.1 简单静态障碍场景

该场景中障碍物数量较少，且全部为静态障碍物，主要用于验证模型是否能够学习到最基本的目标趋近与绕障能力。由于环境结构相对简单，该场景通常适合作为训练初期的基础验证环境。

#### 3.6.2 密集静态障碍场景

该场景中障碍物数量较多，分布更加密集，车辆可行路径更窄。该场景用于考察模型在复杂静态结构中的局部路径选择能力和绕障稳定性。

#### 3.6.3 动静混合障碍场景

该场景同时包含静态障碍物和动态障碍物，是本文重点验证场景。与前两类场景相比，该场景更接近真实环境中的避障任务，能够测试模型在动态不确定环境下的实时决策能力和鲁棒性。

通过上述 3 类场景的设计，本文能够较为完整地覆盖任务书中提出的静止障碍与运动障碍避障需求，并为后续实验结果分析提供对比基础。

### 3.7 环境终止条件设计

为了保证训练过程规范可控，本文为每个回合设置了明确的终止条件。当满足以下任一条件时，当前回合结束：

1. 车辆到达目标点；
2. 车辆与障碍物发生碰撞；
3. 车辆达到最大步数限制。

其中，最大步数限制的设置用于避免个别回合因策略不佳而长时间无法结束，保证训练效率和样本采集稳定性。

### 3.8 本章小结

本章对无人智能车辆避障仿真环境进行了设计，详细介绍了环境总体结构、状态空间、动作空间、奖励函数、障碍物建模及测试场景设置。所构建环境既满足静态和动态障碍场景验证需求，又能够与深度强化学习算法有效结合，为后续模型训练与实验分析提供了实验基础。

## 第 4 章 深度强化学习模型训练与实现

### 4.1 系统实现平台

本文的无人智能车辆避障模型基于 Python 平台实现。Python 语言具有语法简洁、生态完善、科研工具丰富等优点，适用于深度学习与强化学习相关实验开发。为了提高开发效率和实验可复现性，本文选用了多个成熟开源工具完成系统实现。

具体实现平台如下：

1. Python：作为主要开发语言；
2. PyTorch：用于深度神经网络相关计算；
3. Gymnasium：用于构建强化学习交互环境；
4. Stable-Baselines3：用于调用成熟的 PPO 算法实现；
5. Matplotlib：用于训练过程和实验结果可视化。

在项目工程中，本文将代码划分为环境模块、训练模块、测试模块和场景配置模块，以提高程序结构清晰度和后续扩展性。

### 4.2 算法选型与实现思路

根据任务书要求，本文需要构建深度强化学习模型，在静态和动态障碍场景中对模型进行训练直至收敛。结合无人智能车辆避障任务特点，本文选择 PPO 作为核心训练算法。

PPO 适用于序列决策问题，能够在与环境不断交互的过程中逐步优化策略。与 DQN 相比，PPO 在复杂策略更新中的稳定性更好；与一些实现较复杂的连续控制算法相比，PPO 在工程实现上更简洁，便于本科阶段完成完整实验闭环。因此，本文使用 Stable-Baselines3 中的 PPO 实现作为训练核心。

在模型实现过程中，车辆环境在每一步向策略网络提供当前状态向量，策略网络输出一个离散动作编号，对应车辆的运动方向。环境根据该动作更新车辆位置、障碍物状态，并计算奖励值与终止条件，从而完成一次强化学习交互循环。

### 4.3 模型训练流程

本文的模型训练流程主要包括以下步骤：

1. 选择训练场景并初始化环境；
2. 构建 PPO 模型与策略网络；
3. 设置学习率、折扣因子、批大小等训练参数；
4. 智能体与环境交互采样，收集状态、动作、奖励等信息；
5. 根据 PPO 更新规则对策略网络和价值网络进行参数更新；
6. 定期保存训练模型及训练日志；
7. 训练结束后保存最终模型并生成训练曲线。

在工程实现中，训练脚本支持通过命令行传入场景名称和训练步数。例如，可针对混合动态场景运行指定步数训练，并在训练结束后自动保存模型文件、训练日志文件与奖励曲线图。这种实现方式既方便实验重复，也便于后续对不同场景开展对比研究。

### 4.4 训练参数设置

训练参数的合理设置对模型收敛效果具有重要影响。结合 PPO 算法特性与本文避障任务需求，本文在实现中使用了如下主要参数：

1. 学习率：用于控制参数更新步长；
2. 折扣因子：用于衡量长期奖励的重要性；
3. 批大小：用于参数更新时的样本规模；
4. 采样步长：用于每轮 PPO 采样交互长度；
5. 熵正则项系数：用于保持策略探索能力；
6. 裁剪范围：用于限制新旧策略差异。

在训练初期，参数设置以保证训练稳定性为主；在后续实验中，可结合不同场景复杂度调整训练总步数，以获得更好的收敛效果。一般而言，简单静态场景所需训练步数较少，而含动态障碍物的混合场景需要更长训练过程才能获得较优策略。

### 4.5 训练结果记录与可视化

为了便于分析模型训练效果，本文在训练过程中记录每轮训练回合的奖励信息，并在训练结束后自动生成训练摘要和奖励曲线图。训练摘要中包括场景名称、训练步数、记录回合数量、末尾若干回合平均奖励以及最佳奖励等信息；奖励曲线图用于直观展示模型在训练过程中的收敛趋势。

通过可视化结果，可以观察到模型是否逐步提高累计奖励，以及是否存在训练不稳定或长期无提升等问题。若奖励均值随着训练推进逐渐上升，通常说明模型正在学习有效避障策略；若奖励长期无明显改善，则需要检查奖励函数设计、状态空间构成或训练参数设置是否合理。

### 4.6 模型测试与评估实现

在模型训练完成后，本文使用独立评估脚本对训练好的模型进行测试。测试阶段不再进行参数更新，而是固定使用训练后的策略模型，在不同测试场景中反复运行多个回合，并统计如下指标：

1. 成功率；
2. 碰撞率；
3. 平均奖励；
4. 平均步数。

同时，测试程序将每个场景的评估结果保存为报告文件，并生成对应奖励变化图，便于后续实验对比和论文结果整理。

### 4.7 初步训练现象分析

在项目开发过程中，本文已对部分场景进行了短步数试训练。实验现象表明，在简单静态障碍场景中，随着训练步数增加，平均奖励呈现上升趋势，说明模型逐渐学会趋近目标并减少无效运动。在包含动态障碍物的混合场景中，训练难度明显高于简单场景，奖励提升速度较慢，但整体趋势仍表现为逐步改善。这一现象说明动态障碍环境对策略学习提出了更高要求，同时也验证了进一步增加训练步数的必要性。

需要说明的是，短步数训练主要用于验证环境与算法链路是否正确打通，并不能直接代表最终收敛结果。后续正式实验仍需在更长训练步数下开展，以获得稳定可分析的测试结果。

### 4.8 本章小结

本章介绍了基于 Python 平台的无人智能车辆避障模型实现方法，说明了 PPO 算法选型依据、训练流程、参数设置、结果记录方式以及模型测试方法。通过构建完整的训练与评估链路，本文实现了从仿真环境设计到强化学习策略训练再到多场景测试验证的完整实验流程，为后续实验结果分析提供了实现基础。
