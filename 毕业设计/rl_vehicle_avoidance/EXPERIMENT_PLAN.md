# 实验方案

## 1. 实验目标

围绕任务书要求，本项目实验目标如下：

1. 构建无人智能车辆避障深度强化学习模型。
2. 在静态障碍和动态障碍场景中完成训练。
3. 在不少于 3 个测试场景中验证模型性能。
4. 分析模型收敛性、避障成功率和碰撞率。

## 2. 实验平台

- 编程语言：Python 3.12
- 深度学习框架：PyTorch
- 强化学习框架：Stable-Baselines3
- 算法：PPO
- 仿真环境：自定义二维连续空间环境

## 3. 场景设置

### 场景 1：static_easy

- 少量静态障碍物
- 用于验证模型是否能够学会基础避障与到达目标

### 场景 2：static_dense

- 较密集静态障碍物
- 用于验证模型在复杂静态环境中的绕障能力

### 场景 3：mixed_dynamic

- 同时包含静态障碍物和动态障碍物
- 用于验证模型在动态环境中的鲁棒性和实时决策能力

## 4. 状态空间设计

状态向量包括：

1. 车辆当前位置
2. 目标点相对位置
3. 与边界的相对距离
4. 最近 3 个障碍物的相对位置
5. 障碍物半径
6. 障碍物速度

## 5. 动作空间设计

采用离散动作空间，共 8 个动作：

1. 向右
2. 右上
3. 向上
4. 左上
5. 向左
6. 左下
7. 向下
8. 右下

## 6. 奖励函数设计

奖励由以下几部分组成：

1. 接近目标点：正奖励
2. 每移动一步：微小负奖励
3. 靠近障碍物：惩罚
4. 与障碍物碰撞：大惩罚
5. 成功到达目标：大奖励

该奖励设计的目的，是同时鼓励智能体：

- 更快到达目标
- 尽量避开障碍物
- 减少无效游走

## 7. 训练方案

1. 基础训练：`static_easy`，50000 步
2. 强化训练：`static_dense`，50000 步
3. 综合训练：`mixed_dynamic`，80000 到 100000 步

## 8. 评价指标

1. 成功率
2. 碰撞率
3. 平均奖励
4. 平均步数
5. 收敛曲线

## 9. 结果展示

1. 不同场景的测试指标表格
2. 每轮训练奖励变化曲线
3. 成功避障路径示意图
4. 典型失败案例分析

## 10. 实验结论方向

1. PPO 能够在静态和动态障碍场景下完成无人车避障任务。
2. 障碍物越复杂，模型训练难度越高、收敛越慢。
3. 动态障碍场景更能体现深度强化学习方法的在线决策优势。
